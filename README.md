# ONYX-Nexus: Advanced Branching Architecture (Remake)

ONYX-Nexus has been rebuilt with a focus on stability, autonomous verification, and multi-agent coordination through a logical branching system.

## 🚀 Key Features

- **Branching Logic (Dallanma)**: Tasks are logically split into independent sub-branches (Architect, Developer, Sentinel).
- **Autonomous Testing**: Each branch undergoes an isolated self-test cycle before merging into the main consciousness.
- **Supervisor Oversight**: A central supervisor agent ensures 100% test passing and architectural integrity.
- **Hybrid Stack**: High-performance Node.js Supervisor (Express/WS) integrated with deep Python Agent engines (FastAPI/CrewAI).

## 📂 Architecture

- `/src`: Modern React/TypeScript Command Center.
- `/server.ts`: Node.js Supervisor & WebSocket Bridge.
- `/main.py`: Core Agent Logic & Integration Layer.
- `/branching_engine.py`: Python-side branching and self-testing module.

